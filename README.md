## Hosting: Cloudflare Workers (static assets)
- Proyecto conectado a este repo, rama `master`.
- Comando de compilación: `bash build.sh` (genera `dist/`)
- Comando de implementación: `npx wrangler deploy` (lee `wrangler.jsonc`)
- `_headers` define caché y cabeceras de seguridad.
